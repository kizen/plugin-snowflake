Initial release of Snowflake Connector

- This directory contains two Python code steps for interacting with Snowflake via the SQL REST API v2. Both use Programmatic Access Tokens (PAT) for auth.
- snowflake_get: Read-only queries against Snowflake. Returns query results as strings.
- snowflake_send: Write operations against Snowflake. Returns number of runs effected or result dataset.
